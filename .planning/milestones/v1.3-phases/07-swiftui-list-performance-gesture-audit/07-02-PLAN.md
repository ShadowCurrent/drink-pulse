Create the three pure value types the rest of Phase 7 is built on, each with unit tests, before
any view is rewired. All three are `Domain`-adjacent pure code with no `ModelContext`, no
persistence, and no SwiftUI — which is exactly what makes their verification objective rather than
visual.

- **A6-1** (`worth-fixing`): `UserProfile?` — an `@Observable` SwiftData class — is threaded into
  every row, so editing body weight or the weekly goal invalidates every visible row. Replace it
  with a small POD carrying only the three units a row renders.

  pass — once for display, once for the accessibility label, which is a plain computed property
  evaluated eagerly whether or not VoiceOver is running. Compute once into a value type.
- **B8-1 / A4-2 / B8-2** (`worth-fixing` × 2, `nit`): a `Dictionary(grouping:)` plus two sorts plus
  up to seven locale-aware date formats run inside `HistoryListQueryView`'s `body` on every
  evaluation. Move that into one pure, injectable, testable function returning precomputed sections.

Purpose: land the testable core first so the view rewiring in 07-03 and 07-05 is mechanical.
Output: two new value types, one new model type plus its producing function, and three test suites.

Runs in parallel with 07-01 (wave 1) — zero file overlap.
