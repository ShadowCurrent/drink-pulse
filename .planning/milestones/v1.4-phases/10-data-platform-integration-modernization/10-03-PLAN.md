<interfaces>
Export JSON (ExportBundle): `version` Int (supported 1 and 2), `exportedAt` ISO8601 (no fractional seconds), `events[]`, optional `templates[]`, optional `profile`. Event keys: uuid?, timestamp (the consumption date), creationDate?, volumeMl, abv, quantity (default 1), enteredUnit?, category, icon, customName?, notes?, price?, priceCurrency?, modifiedDate?. Template keys: uuid?, name, category, defaultVolumeMl, abv, icon, colorHex, isFavorite, isArchived, modifiedDate?. Profile keys: bodyWeightKg, biologicalSex, dateOfBirth?, guidelineChoice, weeklyGoalGrams, unitSystem, currency, abvPrecisionPermille, alcoholUnit, modifiedDate?. `healthKitUUID` is never exported.
`DataImporter().importData(_:into:)` is @MainActor, returns ImportResult(imported, skipped, failed, errors). Events with a uuid upsert by modifiedDate; events without one are de-duplicated by date, volume, abv and quantity. Templates without a uuid are always inserted new, so every fixture template must carry a uuid.
`BackupExport(events:templates:profile:).encoded()` produces the export JSON.
Test targets are file-system-synchronized folders; whether a JSON file placed there reaches the test bundle is unproven (Pitfall 2).
