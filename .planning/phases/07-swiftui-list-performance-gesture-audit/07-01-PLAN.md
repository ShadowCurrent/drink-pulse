  risk profile and its own verification, and folding it into a performance-fix phase is exactly

  deployment target stays iOS 26 (CLAUDE.md: non-negotiable). No task cites an unverified API name.

  reconciliation to whoever formally closes that plan. X1 (`history-scrollview-bugs.md` archived as
