<objective>
Extend both Insights charts with a full `AXChartDescriptorRepresentable`
conformance, attached via `.accessibilityChartDescriptor(_:)`, so
VoiceOver users can access every plotted point's date/weekday + value
through the audio-graph Rotor action — independent of the drag gesture
built in 05-01-PLAN.md — satisfying CHART-03's "scrubbing is not the
only path to the values" requirement (D-08, D-09).

Purpose: CHART-01/CHART-02's scrub interaction is gesture-only; a
VoiceOver user who cannot perform a drag still needs full per-point
access. This plan delivers that independent path.

Output: two new `+Accessibility.swift` files (one per chart, each under
the file-size ceiling per CLAUDE.md's splitting convention), the
`.accessibilityChartDescriptor(_:)` attachment on each chart, and two new
unit test files proving descriptor construction correctness.
</objective>
